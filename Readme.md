# Ping Pong

シンプルな2人用協力Ping Pong（ピンポン）ゲームです。  
2人で息を合わせて、変化するボールのスピードとサイズに立ち向かいましょう！

## 🕹️ 遊び方

* **Wキー**：左パドルを上に動かす
* **Sキー**：左パドルを下に動かす
* **↑キー**：右パドルを上に動かす
* **↓キー**：右パドルを下に動かす

ボールを落とさないように、2人で協力して打ち返し続けましょう。

## 🌟 ゲーム内容と特徴

* **ポイント＆レベルアップ**：ボールを打ち返すとスコアとXPが増え、一定のXPでレベルアップします。
* **加速するスピード**：レベルアップするごとにボールのベース速度がどんどん増していきます。
* **縮小するボール**：レベルアップするごとにボールのサイズ（半径）が小さくなり、狙いを定めるのが難しくなります。
* **⚡ 独自開発の「魔球」システム**：作者オリジナルの計算式（`fabsf` や `sqrtf`）により、レベルアップするほどボールの縦横のスピードにトリッキーな緩急（かんきゅう）がつきます。一瞬も油断できない予測不能なラリーが楽しめます！
* **軌道予測線**：ボールの進む先がうっすらと線で表示されるため、激しいスピード変化にも戦略的に対応できます。
* **ゲームオーバー**：ボールを画面の外に落とすとゲームオーバーです。

## 💻 動作環境

* Windows
* OpenGL対応環境（OpenGLが必要です）
* raylib

## 📦 使用方法

1. ダウンロードした `Setup.exe` を起動し、インストールします。
   * インストールの際、パスワード **`0000`** の入力が必要です。
2. デスクトップにショートカットが作成されますので、そこから起動します。
3. お楽しみください。
