# Ping Pong



シンプルな1人用Ping Pongゲームです。



## 遊び方



**↑キー**：パドルを上に動かす

**↓キー**：パドルを下に動かす



ボールを落とさないように打ち返し続けましょう。



## ゲーム内容



* ボールを打ち返すとスコアが1増えます。

* ボールを打ち返すとXPが増えます。

* 一定のXPがたまるとレベルアップします。

* レベルアップするとボールが小さくなり、ゲームが難しくなります。

* ボールを落とすとゲームオーバーです。



## 動作環境



* Windows

* OpenGL対応環境（OpenGLが必要です）

* raylib



## 使用方法

* `Setup.exe` を起動しインストールします。
* デスクトップにショートカットができますので起動します。
* お楽しみください。
